# Roadmap 26: Admin Catalogs (`/admin/exercises`, `/admin/foods`)

## 🎯 Objetivo General
Auditar la gestión del catálogo maestro de ejercicios y biblioteca de alimentos: creación, edición, borrado, carga de vídeos de demostración e internacionalización de nombres.

---

## 📋 Lista de Tareas

### 🟢 Tarea 26.1: Catálogo Maestro de Ejercicios (`/admin/exercises`)
- **Estado:** `[COMPLETADO]`
- **Descripción:** Editor completo de ejercicios con grupos musculares, dificultad, equipamiento y URL de vídeo de técnica.
- **Archivos:** `src/pages/admin/exercises.astro`, `src/lib/shared/exerciseLibrary.ts`.

### 🟢 Tarea 26.2: Biblioteca Maestra de Alimentos (`/admin/foods`)
- **Estado:** `[COMPLETADO]`
- **Descripción:** Base de datos de alimentos con calorías, macronutrientes por porción y alérgenos asociados.
- **Archivos:** `src/pages/admin/foods.astro`, `src/lib/shared/foodLibrary.ts`.
