# Planner Agent — Checklist

Checklist para cada sesión de planificación:

- [ ] Revisar TODO.md y entender estado actual del proyecto
- [ ] Verificar TASK.md para saber la tarea actual en curso
- [ ] Consultar agents/__master.md para ver locks y estados de agentes
- [ ] Identificar tareas bloqueadas por dependencias
- [ ] Priorizar backlog según dependencias y urgencia
- [ ] Asignar tarea a agente (verificar lock libre)
- [ ] Actualizar TASK.md con la nueva tarea asignada
- [ ] Actualizar TODO.md reflejando nuevo estado
- [ ] Reportar estado general
